## 0.1.0

- Initial release.
- `lintMarkdown` lints Markdown with rumdl's default rule set and reports rule
  name, message, source range, severity, and fix availability.
- `formatMarkdown` formats Markdown with rumdl's default formatter.
- Ships with a Native Assets build hook for Android, iOS, Linux, macOS, and
  Windows, plus WASM support for Web.
